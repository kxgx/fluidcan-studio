远程仓库 OTA（GitHub Release）

0.2.16 起 Release 只发布结构化 zip（OTA/firmware.bin + USB/firmware.factory.bin），Studio 自动下载并解包；4 MB 单 app 分区版本不能网络 OTA，只能串口/Web Serial 烧录。
--
请选择固件分类。
--

网络 OTA（本地文件）

设备需在线；支持 Release 结构化 zip（自动提取 OTA/firmware.bin）或 app .bin；上传到 /updatefw，完成后自动重启。
--

串口烧录（本地 factory 镜像）

使用官方 esptool 写本地 factory 镜像到 0x0：选 .bin（firmware.factory.bin）或含 firmware.factory.bin 的 .zip。首次使用可能需要下载官方 esptool。
--

浏览器 Web Serial 烧录

Chrome/Edge + USB。Studio 不再捆绑固件：请准备本地 .zip（标准命名）或单个标准命名 .bin，生成清单时可勾选只更新特定分区；点“连接串口并烧录”由浏览器直接写入，无需安装 Python/esptool。烧录会覆盖所选分区，请先备份 config.yaml。Web Serial 需要 localhost/HTTPS 页面（Tauri 窗口或本机 http://127.0.0.1 均可用）。
--
选择固件包后显示可烧录分区
